
# Assignment01-GitHub-Basics

## Assignment 01 — Getting Started with GitHub

### Program Description
This C++ program calculates the sum of the first 50 natural numbers using two methods:

1. A for loop that adds numbers from 1 to 50.
2. The formula n(n+1)/2, where n = 50.

Both methods produce the same result: 1275.

### Sample Output
```text
Sum of first 50 natural numbers (loop): 1275
Sum using formula n(n+1)/2: 1275
```
